## Known deviations

These are differences from JavaScript or the frameworks that the M2 implementation accepts rather than rejects. Each is either inherent to the static value model or scheduled.

| Area | Deviation | Plan |
|---|---|---|
| Svelte `$state` | Proxy identity and raw-write visibility are not modelled: a raw reference kept after storing an object into deep state compares equal to the stored value and shares later mutations, unlike Svelte's proxy | M3 (runtime ownership) |
| Array reads | `a[i]` typed as `T` (not `T \| undefined`) throws `RangeError` when out of range, where JavaScript yields `undefined`; arrays are dense, so holes are not represented | inherent; reads typed as nullable (`at()`, `noUncheckedIndexedAccess`-style code) behave exactly |
| Array callbacks | `find*` skip indices a callback removed (JavaScript passes `undefined`); `map` omits such holes | inherent to dense arrays |
| `Map`/`Set` keys | a `-0` key is stored as first inserted, so `keys()` may return `-0`; lookups are correct | low priority |
| Transcendentals | `Math.sin`, `exp`, `log` etc. may differ from V8 by one ulp (Rust libm vs V8's ieee754 port); exactly specified functions match | M10 if an app observes it |
| `localeCompare` | code-unit order instead of ICU root collation; explicit locales are rejected | M5 |
| Strings | literals with lone surrogates are rejected; computed lone surrogates render as U+FFFD at the DOM boundary | inherent at the boundary |
| Heap | reference cycles leak (`Rc`) | M10 option |
| Deep tracking | any heap mutation marks every deep cell dirty; harmless for rendering, must be refined before effects (M4) | M4 |

Not supported yet (rejected with diagnostics): classes, `async`/`await`, generators, `RegExp`, `Date`, `Math.random`, getters/setters, `in`/`instanceof`, rest parameters, computed keys, logical assignment, map iteration of entries.

**Still incomplete, unchanged from Phase 4:** OS keyboard delivery, platform IME and Wayland resize. The additional Vue 3.5.24 and Svelte 5.49.2 pins are not in the automated campaign. Isolated deployment packaging has not been rerun since the restructure.
