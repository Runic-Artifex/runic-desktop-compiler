Source: commit tagged `m4`. Browser: Chromium 153.0.8010.12 (headless, Playwright 1.63.0 from nixpkgs). Native: debug probe builds with the CPU renderer; release builds for measurement. The Svelte reference is compiled for production (see [M4-EFFECTS](../../docs/design/M4-EFFECTS.md#outcome)).

New in M4, all in React, Vue and Svelte:
- the event loop: tasks, microtasks, flush jobs and default-priority tasks, with virtual time in tests;
- effects with each framework's phases, orders and cleanups;
- timers, promises and `async`/`await`;
- `localStorage`, with a `reload` action in all three harness sides;
- `tick()` (Svelte) and `nextTick()` (Vue);
- cached derived values;
- dependency tracking per record field, array element and length;
- rejection of template reads that would expose re-render granularity (`E_REACTIVITY`), and read-only React state and props (`E_READONLY`).

New examples: 7GUIs Timer and TodoMVC with persistence. New cases:
- **Effect order:** `effects`, `effects-swap`, `effect-order`, `effect-writes-state`, `passive-effect-writes-state`, `layout-effect-writes-state`.
- **Timing and async:** `flush-timing`, `closures`, `promises`.
- **Derived values and tracking:** `derived-timing`, `deep-tracking`.
- **Examples:** `7guis-timer`, `todomvc-persistence`.

## Known deviations

M3's list still applies, except where noted.

| Area | Deviation | Plan |
|---|---|---|
| Update granularity (M3) | Replaced: template reads where it would be observable are rejected (`E_REACTIVITY`) | done |
| React mutation (M3) | Replaced: React state and props are read-only (`E_READONLY`); props are tracked by identity | done |
| Event dispatch, interpreter timers, refs read while rendering (M3) | Fixed by the flush model | done |
| Loop guards | React throws after 50 nested updates and Vue only warns in development; Runic stops after 1000 passes | inherent |
| Vue raw objects | A raw object captured before it was stored in a `ref` is tracked natively; Vue tracks only access through the reactive proxy | low priority |
| Unhandled rejections | not reported (the browser logs them) | M5 console |
| Style attributes (M3) | still serialised literally rather than through the CSSOM | M5 |
| Navigation after a move-induced blur (M3) | unchanged (case `reorder-navigation`) | M5 focus model |
| Svelte proxies (M3) | lazy proxy snapshots not modelled (case `ownership-cycles`) | low priority |

Rejected rather than modelled, each with a diagnostic:
- **Vue:** the watcher queue order when a watcher writes what another watcher reads; unmount work at the removal point of a patch.
- **React:** the element-position order of unmount cleanups.
- **Vue watchers:** `flush: 'post' | 'sync'` and `onUpdated`.
- **`async` functions:** `finally` around `await`, and `await` nested in other expressions.

**Still incomplete, unchanged since Phase 4:** OS keyboard delivery, platform IME and Wayland resize. The additional Vue 3.5.24 and Svelte 5.49.2 pins are not in the automated campaign.
