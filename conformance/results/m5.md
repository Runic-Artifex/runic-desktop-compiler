New in M5 ([M5-PLATFORM](../../docs/design/M5-PLATFORM.md)), in React, Vue and Svelte unless noted:
- **Events:** the DOM event model (capture, bubble, `preventDefault`, `stopPropagation`), keyboard, pointer and mouse sequences in Chromium's order, `dblclick`, `contextmenu`, wheel; window and document listeners.
- **Components:** rest props and spread attributes, `class:`/`style:` directives and React style objects through a CSSOM (`runic-css` over Stylo), component refs.
- **Forms:** `textarea`, `label`, `select` with a popup drawn by the runtime, radio groups.
- **Focus:** focus events with `relatedTarget`, `focus()`/`blur()`, `tabindex` and Tab order, blur when the focused element is removed or moved (nested in the update; React ignores events during its commit), focus fixup in the rendering step.
- **Layout and media:** layout reads with Blink's pixel snapping, programmatic scrolling and `scrollIntoView`, `scroll` events and scroll clamping, `matchMedia` with `change` events, the window `resize` event, the document element (theming).
- **Host services:** console, clipboard, history and hash routing, `Date` and an `Intl` subset (ICU data pinned to Chromium's), `RegExp` (`runic-js` over `regress`), seeded randomness.
- **Inline SVG icons** (an allow-listed subset, drawn by Blitz through usvg).

New examples: 7GUIs Flight Booker, Circle Drawer and Cells in all three frameworks; a virtualized 10,000-row list in Svelte and Vue. New cases (41):
- **Events:** `events`, `events-vue`, `shortcuts`.
- **Components and styles:** `rest-props`, `rest-attrs-react`, `class-directives`, `style-directives`, `style-objects`, `component-refs`, `component-refs-react`.
- **Forms:** `forms`, `forms-react`, `forms-vue`, `select`, `select-react`, `select-vue`, `select-popup`, `radio`, `radio-react`, `radio-script`.
- **Focus:** `focus`, `edit-blur`, `focus-fixup`.
- **Layout and media:** `measure`, `scroll-events`, `theme`, `media-events`.
- **Services:** `console`, `clipboard`, `hash-router`, `hash-router-start`, `time`, `time-berlin`, `time-new-york`, `patterns`, `randomness`.
- **Rendering:** `icons`.
- **Examples:** `7guis-flight`, `7guis-circles`, `7guis-cells`, `virtual-list`.

## Known deviations

M4's list still applies, except where noted.

| Area | Deviation | Plan |
|---|---|---|
| Unhandled rejections (M4) | still not reported (the browser logs them) | M6 |
| Style attributes (M3) | Replaced: inline styles serialise through the CSSOM | done |
| Navigation after a move-induced blur (M3) | unchanged (case `reorder-navigation`): modelling it needs each framework's exact DOM move sequence, and only Tab right after the focused item is reordered observes it | M8 |
| Svelte proxies (M3) | lazy proxy snapshots not modelled (case `ownership-cycles`) | low priority |
| Pointer targets | Playwright scrolls a partly hidden pointer target into view first; the probe does not, and refuses such targets in browser comparisons | cases click visible elements |
| Pixel margin | `forms-vue` at 420 px reaches MAE 2.96 of 3 (the text-area-in-flex-row Blitz gap) | Blitz fork |
| Blitz rendering | shrink-to-fit rounding, inline control baselines, text input line height, placeholders, the focus ring, textarea scrolling, hyphen breaks, SVG `currentColor` inheritance and CSS on SVG content; fixtures avoid them ([BLITZ-GAPS](../../docs/BLITZ-GAPS.md)) | Blitz fork |
| SVG startup | Blitz loads every system font for the first inline `<svg>` (usvg's font database) | Blitz fork |

Moved out of M5 (see the [roadmap](../../docs/ROADMAP.md)): `ResizeObserver`, `Intl.PluralRules`/`DisplayNames` and React virtualized lists to M6, fetch of local resources to M7, window title and size to M8 packaging, AccessKit to the desktop-input track, placeholders to the Blitz fork.

Rejected rather than modelled, each with a diagnostic (selection):
- **React:** `onWheel`; window `scroll` and `resize` listeners; continuous-event handlers (move, enter, leave, scroll) whose state is rendered other than as text or paint-only colours; uncontrolled `defaultValue` and `multiple` selects; radio groups not provably exclusive.
- **Vue:** `.once`, `.capture`, `.passive`; `:checked` on radio buttons; `v-model` with `@change` where the flush between them is observable.
- **All:** `Intl` options and locales outside the verified subset; SVG elements and attributes outside the allow-list; SVG-only CSS properties; `<input type="range">`.

**Still incomplete, unchanged since Phase 4:** OS keyboard delivery, platform IME and Wayland resize. The additional Vue 3.5.24 and Svelte 5.49.2 pins are not in the automated campaign.
